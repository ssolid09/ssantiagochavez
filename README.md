# Santiago Chavez · Web personal

Sitio web personal de una sola página (HTML, CSS y JavaScript, sin dependencias).

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `santiagochavez` o `usuario.github.io`.
2. Sube estos archivos a la rama `main`.
3. En el repositorio ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
5. En un par de minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Dominio propio (santiagochavez.cl)

1. En **Settings → Pages → Custom domain** escribe `www.santiagochavez.cl` y guarda (GitHub crea el archivo `CNAME`).
2. En el panel de tu dominio crea un registro **CNAME** de `www` hacia `TU-USUARIO.github.io`.
3. Activa **Enforce HTTPS** cuando esté disponible.

## Editar

Todo el sitio está en `index.html`. Los textos, los enlaces de redes sociales (hoy con `href="#"`) y los proyectos se cambian directamente ahí.
